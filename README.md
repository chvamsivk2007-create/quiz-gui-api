Quiz App using API ❓🌐
A GUI-based quiz application built with Python and Tkinter that fetches trivia questions from an online API.

📖 Description
This project uses the Open Trivia Database (OpenTDB) API to retrieve quiz questions dynamically and present them through an interactive graphical interface.

The application keeps track of the user's score and provides instant feedback for each answer.

✨ Features
Fetches questions from an online API
Interactive Tkinter GUI
Real-time score tracking
True/False quiz format
Automatic question updates
Dynamic content using JSON data

🛠️ Technologies Used
Python 3
Tkinter
Requests
Open Trivia Database API (OpenTDB)
